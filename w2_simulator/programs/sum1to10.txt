# sum1to10.txt — 1부터 10까지 더하는 MIPS 프로그램 (정답: 55)
#
# 형식
#   - 한 줄에 32비트 명령어 하나를 16진수로 적는다. "0x" 접두사는 있어도 없어도 된다.
#   - '#' 뒤는 주석이다. 줄 전체를 주석으로 써도 되고, 명령어 뒤에 붙여도 된다.
#   - 빈 줄은 무시한다.
#   - 첫 줄의 명령어가 주소 0x00000000, 다음 줄이 0x00000004, ... 에 놓인다.
#
# 예시 (형식 설명용, 이 프로그램의 일부가 아님)
#   0x22300005    # addi $s0, $s1, 5
#
# 손 어셈블 체크리스트 (L9c)
#   - beq 오프셋 = (목적지 주소 - (beq 주소 + 4)) / 4  → 명령어 개수 단위, 기준은 PC+4
#   - 뒤로 가는 분기는 음수 오프셋 → 16비트 2의 보수(two's complement)로 적는다
#   - 결과(55)를 어느 레지스터 또는 데이터 메모리 주소에 남길지 정하고 주석으로 적어 둔다
